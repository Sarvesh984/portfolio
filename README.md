# Sarvesh Chakravarthy — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It presents selected projects, skills, certificates, background, and contact links in a single-page layout.

## Features

- Responsive layout with light and dark themes
- Project cards linking to their source repositories
- Certificate image viewer
- Public GitHub profile and repository data loaded from the GitHub API
- Contact form that opens a prefilled email draft in the visitor's mail app

## Run locally

Open `index.html` in a browser. The page loads Google Fonts and public GitHub data over the internet; those parts need an active connection. No build step or package installation is required.

## Project files

- `index.html` — page markup, styles, and browser-side JavaScript
- `images/` — profile photo, project previews, and certificate images

The portfolio displays public GitHub data only. It does not read private repository details.
